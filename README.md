# RayelleBX
BepInEx based Browndust2 Plugins  (OverwhelmIndicator)


# cfg 기반 플러그인 활성화
  ┌────────────────────────────────────┬───────────────────────────────────────────────────────────┐
  │                파일                │                           내용                            │
  ├────────────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ Helpers/PluginConfig.cs            │ 신규 — cfg 파서. # 주석 무시, key = value 파싱            │
  ├────────────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ setting.cfg                        │ 신규 — 기본 설정 파일                                     │
  ├────────────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ Plugin.cs                          │ PluginConfig.Load() 호출 추가 (Harmony 패치 등록 전)      │
  ├────────────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ Patches/OverwhelmIndicatorPatch.cs │ Postfix 진입 시 PluginConfig.OverwhelmIndicator 체크 추가 │
  ├────────────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ RayelleBX.csproj                   │ PluginConfig.cs 컴파일 등록, 빌드 시 setting.cfg 배포     │
  └────────────────────────────────────┴───────────────────────────────────────────────────────────┘

  동작 방식
  - setting.cfg의 OverwhelmIndicator = false로 바꾸고 게임을 재시작하면 인디케이터가 동작하지 않는다
  - cfg 파일이 없으면 기본값 true로 동작하므로 기존 사용자에게 영향 없다
  - 배포 규칙: 빌드 시 cfg가 이미 플러그인 폴더에 있으면 덮어쓰지 않아 사용자 설정이 보존된다
